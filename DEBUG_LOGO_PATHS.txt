Logo Loading Debug Information:

The application tries to load the bear logo in this order:

1. First: Same directory as the .exe file
   Path: [executable_directory]\bear_logo.ico
   
2. Second: Current working directory  
   Path: [working_directory]\bear_logo.ico
   
3. Third: PNG backup in working directory
   Path: [working_directory]\bear_logo.png

TROUBLESHOOTING:
- Make sure bear_logo.ico is in the same folder as external-cheat-base.exe
- If using ICO doesn't work, try converting to PNG format
- The fallback orange circle appears when logo loading fails

EXPECTED LOCATIONS:
- external-cheat-base-master\x64\Release\bear_logo.ico
- OR external-cheat-base-master\bear_logo.ico (if running from project root)

The white circle in the menu indicates the texture loaded but may be rendering incorrectly.
The orange circle on startup indicates the fallback is being used.
